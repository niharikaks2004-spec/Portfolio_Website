## Running Locally

No build tools or dependencies required.

```bash
git clone https://github.com/<your-username>/portfolio.git
cd portfolio
```

Then simply open `index.html` in your browser.

## Deployment

This is a static site, so it can be hosted for free on:

- **GitHub Pages** — Settings → Pages → set source to `main` branch
- **Netlify** — drag and drop `index.html` at [app.netlify.com/drop](https://app.netlify.com/drop)
- **Vercel** — import this repo at [vercel.com](https://vercel.com)
